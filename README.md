## 👋 프로젝트 소개
웹 서비스 기능을 구현하여 실시간 예약기능을 사용해 아키텍처 패턴을 공부하기 위해 이 프로젝트를 진행해보게 되었습니다.

## 📆 개발 기간
2025-05-29 ~ 2025-06-12

## 🤓 팀원 소개
### 조수현(팀장)
+ 챗봇 기능
+ 전반적인 조율
### 최가희
+ 날짜 예약 기능
+ 실시간 예약 및 수정/삭제/조회 기능
+ 반응형 페이지 제작
### 김두민
+ 달력 프론트엔드
+ 관리자 예약 확인 기능
+ 메인 페이지 배너 이미지 교체 기능
### 하주현
+ 메인 페이지
+ 회원가입 페이지
+ 로그인 페이지
